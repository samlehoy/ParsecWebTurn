AMD HEVC live test - test-only build, not a release

Use a separate folder and your copied settings.json. No credentials are bundled.
Select the AMD GPU, Prefer H.265 / HEVC, save and reconnect for each change.

Zero copy OFF: AMD AMF HEVC with D3D11 VideoProcessor / DXGI. The original
NV12 output is consumed on the same decoder device; SurfaceCopy is disabled.
One existing conversion/output write remains. No decoded-frame intermediate
copy, plane split, CPU readback or CPU decoder is introduced.

Zero copy ON: Direct D3D11 HEVC with Original NV12 / Windows Presentation API.
This uses the existing NVIDIA/Intel displayable-surface path on AMD, rather than
copying AMF output into another texture. Hardware/driver capability checks and
bounded presentation leases remain in place. Unsupported paths recover to AMF
or the existing GPU MF path; inspect fallback status rather than assuming a pass.
Windows/driver internal copies and actual scanout are not claimed.

Test WebRTC and BUD independently, including motion, colors/cropping, overlays,
resize/fullscreen and disconnect/reconnect. H.264 remains Media Foundation.
The embedded WASM and both transport implementations are unchanged.
The amd-video-test feature is disabled in ordinary builds.
