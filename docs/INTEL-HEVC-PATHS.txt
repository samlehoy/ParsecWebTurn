Intel HEVC path test - offline, Windows x64

Extract to a separate writable folder on the affected Intel laptop.
Close ParsecWebTurn before starting. No settings.json, login, host or Internet
connection is needed. Run Run-Intel-HEVC-Paths.cmd.

The test first checks the existing synchronous Media Foundation and direct
D3D11 decoders. It then opens synthetic-video windows for Media Engine with
DirectComposition, first with ordinary timing, then real-time timing. Leave
the windows open. Normally this takes 20-40 seconds; each Media Engine trial
has a 20-second upper bound. The synthetic MP4 is created beside the program.

Please send intel-hevc-paths.json and intel-hevc-console.txt.
If a window crashes, send the console file too; the incomplete run is not a pass.
The console can show the last tested GPU even if the final JSON was not written.

Played frames and observed GPU hardware decoding are separate results. The
hardware evidence uses this test process's VideoDecode engine on the exact
adapter LUID. A missing counter is unknown, never a software-decoding verdict.
The test does not establish live-stream latency or internal driver copy counts.
The application never reads back decoded pixels or copies decoded textures.

No changes are made to drivers, Windows codec configuration or Parsec settings.
No code from this probe is added to the live client's video path.
